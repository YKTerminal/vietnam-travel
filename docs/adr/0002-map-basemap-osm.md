# ADR-0002: 地图底图保留 OSM + 失败保底 + Google Maps 主导航

**日期**: 2026-09-24

**背景**: 9/13 曾尝试换高德瓦片（"国内可用"），后又换回 OSM 底图。用户既往标准是"Leaflet + 高德瓦片（OSM 国内被墙）"，但本行程在越南境内。

**决策**:
1. 底图保留 OSM——高德在越南无有效地图数据，换高德等于整图空白
2. 新增图块加载失败保底：检测 tile 加载错误时显示提示条，引导用户点"在 Google Maps 打开"
3. 主导航工具 = Google Maps（用户备注："最好用谷歌地图看"），路线步骤旁保留跳转按钮

**理由**: 越南行程的场景优先级是"越南境内有数据" > "国内访问流畅"。国内访问 OSM 偶发慢/空白是真实风险，但可通过失败保底 + Google Maps 兜底解决；高德方案在越南完全不可用，无法兜底。

**替代方案（已否决）**: 高德瓦片（越南无数据）；纯 OSM 无保底（国内空白时无出路）。
