# ADR-0001: 不设独立"每日行程/待办"模块

**日期**: 2026-09-24

**背景**: 模板 schema 提供 `itinerary` 和 `todo` 两个可选模块。早期版本曾启用"每日行程"，后于 9/13 精简时关闭（config.modules.itinerary=false, todo=false）。

**决策**: 永久关闭独立行程/待办模块。所有行程内容只存在于"本次旅程"板块（`days[]`），景点细节（怎么玩/花费/雨天PlanB）以内联字段形式补进地点卡，不另设平行模块。

**理由**: 用户明确：独立"每日行程"与"本次旅程"的日期行程高度重复，双份展示造成混乱。真实缺口不是"行程模块缺失"，而是地点卡信息密度不足——补齐字段即可，无需新增板块。

**替代方案（已否决）**: 重新启用 itinerary 模块单独渲染每日详情——被用户以"冗余混乱"否决。
